# CanteenWise - Product Messaging

## Product Overview

CanteenWise is a canteen operations dashboard for reviewing meal demand, coordinating orders, monitoring ingredient stock, and tracking food waste. It is a responsive front-end prototype built with Next.js, React, and TypeScript.

## Short Description

CanteenWise helps canteen teams plan meal preparation, manage daily orders, monitor inventory, and understand food waste from one dashboard.

## Key Workflows

- Review daily orders, revenue, demand, and preparation metrics.
- Track order progress from pending through completion.
- Plan meal quantities and add menu items.
- Monitor ingredient levels, coverage, and replenishment risks.
- Log food waste and review sustainability trends.
- Manage example profile and account settings.

## Screens

Dashboard, Orders, Menu & Demand, Inventory, Sustainability, and Profile.

## Technology

Next.js 16 App Router, React 19, TypeScript, Tailwind CSS 4, Recharts, Radix UI primitives, and Lucide icons.

## Project Status

The current version uses illustrative sample data and browser-side state. It is not connected to a production API, database, payment service, or authentication provider.
